# Level 4 — Enterprise Evaluation

This is the layer most architects care about.

Instead of asking:

> Which model is smartest?

Ask:

> Which model delivers the best business outcome?



| Dimension          | Why it matters                              |
| ------------------ | ------------------------------------------- |
| Quality            | Is the answer correct and useful?           |
| Latency            | Will users wait this long?                  |
| Cost               | Can we afford production usage?             |
| Privacy            | Can sensitive data leave the organization?  |
| Context Window     | Can it handle our documents?                |
| Tool Calling       | Does it integrate with enterprise systems?  |
| Structured Output  | Can downstream systems reliably consume it? |
| Governance         | Auditability, compliance, safety.           |
| Deployment Options | SaaS, VPC, on-premises, hybrid.             |
| Vendor Risk        | Lock-in, support, roadmap, SLAs.            |
