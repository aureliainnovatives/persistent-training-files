# FDE-MM Participant Group Activities --- Model Decision Challenges

This participant pack contains five independent 30-minute group
exercises focused on model-mechanics decision making.

1.  Insurance Claims Assistant
2.  Retail Customer Support Agent
3.  Banking Loan Document Assistant
4.  Manufacturing Maintenance Copilot
5.  Software Modernization Assistant

Each activity contains a short customer situation, eight decision
questions, constrained choices, a one-line justification column, and one
final recommendation. There are no trainer notes or answer keys in this
pack.
