# Module 3.2 --- Multi-Agent Workflows & Orchestration

## Suggested 3-hour sequence

1.  Single → multi-agent
2.  Agent specification and boundaries
3.  Topologies
4.  Decomposition/delegation
5.  Coordination/state/handoffs
6.  Failure handling
7.  Evaluation
8.  Framework comparison
9.  Demos/hands-on

## Demo set

Two demos each for LangChain, LangGraph, AutoGen and CrewAI. All
examples use OpenAI via `OPENAI_API_KEY` and mock/illustrative
enterprise scenarios.
